# Code of Conduct

We are committed to making participation in this project a respectful and constructive experience for everyone.

Examples of expected behavior include respectful language, welcoming good-faith feedback, focusing criticism on ideas rather than people, and considering the impact of changes on users and maintainers.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, doxxing, publishing private information, or encouraging unauthorized testing of third-party systems.

Project maintainers may edit, remove, or reject contributions that violate these standards. Report conduct concerns privately to the repository maintainers.
